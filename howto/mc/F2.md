MC doesn't have a built-in shortcut to copy a path to the system clipboard directly, but there are a couple of ways to do it:

**Built-in: insert path into command line**

- `Ctrl+Enter` — pastes the selected file's full path into the MC command line input
- `Ctrl+Shift+Enter` — pastes the full absolute path

You can then copy from the command line, though that's not quite clipboard-direct.

**Practical workaround: user menu macro**

Press `F2` to open the user menu and add an entry like:

```
c   Copy path to clipboard
    echo -n %d/%f | xclip -selection clipboard
```

(use `xclip`, `xsel`, or `wl-copy` depending on your display server)

Then `F2` → `c` copies the current file's full path to clipboard.

**Another option: subshell**

Drop to the subshell with `Ctrl+O`, then:
```bash
echo -n "$(mc_pwd)/filename" | xclip ...
```

The `F2` user menu approach is the most ergonomic for repeated use. The macro variables MC exposes are `%f` (filename), `%d` (directory), `%p` (full path = `%d/%f`), so `%p` alone should work too.
